# 神录剪

随手一录，轻松一剪。

## 下载与安装

从 https://github.com/Kr1shu01/shenlujian/releases 下载最新的 `shenlujian_版本_amd64.deb`。
在 Ubuntu 22.04 或兼容的 64 位 Debian/Ubuntu 桌面上运行：

```bash
sudo apt install ./shenlujian_1.1.1_amd64.deb
```

安装后在应用菜单点击「神录剪」，或在终端运行 `shenlujian`。首次安装需要联网安装系统依赖。当前二进制基于 Ubuntu 22.04 构建；其他发行版尚未验收。
也提供 Linux ZIP，解压后按包内说明安装。源码构建需要 Python 3.10、PyQt5、PyInstaller 6.22.0；构建单文件运行 `./build_shenlujian.sh`，生成 deb 运行 `./build_deb.sh 1.1.1`。

## Wayland

自动识别 Wayland 会话，使用 XDG ScreenCast portal + PipeWire 获取经过系统授权的屏幕画面；选择共享屏幕后输出 MP4。
共享画面的实际像素尺寸由流读取，原始尺寸、1080p、2K、4K和自定义输出均保持画面比例。
自定义区域的坐标从系统对话框中所选屏幕的左上角计算。最小适配版本暂不提供 Wayland 桌面鼠标框选，区域可手动填写。
Wayland 下 F9/F10 在应用窗口内生效，保持窗口可见，也可点击开始 / 停止；X11 的全局 F9/F10 和鼠标框选保持原有行为。
需要桌面提供 ScreenCast portal 后端（GNOME、KDE 或其他对应后端）。当前验收包括原有 X11 录屏与剪辑，以及 Wayland 新录制管线的真实编码、缩放、停止和保存；尚未在实际 Wayland 登录会话中完成桌面录制验收。

单文件 Linux 应用（X11 / Wayland）：默认最大化打开，保留系统标题栏、关闭按钮和 Ubuntu 拓展坞，左侧「录」，右侧「剪」，两侧宽度可拖动调整。
F11 可切换全屏，Esc 返回最大化。录屏和剪辑区域均隐藏滚动条，内容超出时仍可用鼠标滚轮滚动。
录屏默认“全屏录制”，按当前主屏实际尺寸采集，界面不显示或假定固定的屏幕分辨率。连接多屏时，自动列出各屏幕和“所有屏幕”，可以选择单屏或鼠标框选区域；输出原始尺寸、1080p、2K、4K以及自定义尺寸。框选的显示坐标自动换算为 X11 实际像素，输出保持比例；奇数宽高向下调整到偶数，选择预设或自定义输出时显示实际输出尺寸。屏幕接入、移除或分辨率变化时自动更新屏幕选项。
剪辑区采用 [Shotcut 官方功能页](https://www.shotcut.org/features/) 的预览、时间线和导出组织方式。

## 使用

F9 开始录制；F10 停止并保存。全局快捷键在窗口最小化或其他应用处于前台时仍然可用。刚开始便停止也会保存有效首帧。

1. 点击“添加素材…”导入视频或音频，也可拖入文件；选择目录和素材库内容会记忆。选中素材后按 Delete 可移出素材库，原文件及已加入时间线的片段保持原样。
2. 从素材库拖一个或多个视频到预览 / 时间线，或选择素材后点击“加入时间线”。双击素材库中已加入的素材可定位到对应片段。
3. 时间线显示完整项目，播放会连续跨过所有片段；点击任意位置可查看该帧。
4. 拖动时间线中的片段块到其他片段前面或后面，直接调整项目顺序。素材库也可以拖到时间线指定位置插入。
5. 先单击选中视频或音频片段，再在同一片段内双击第一个位置和第二个位置，选中包含两端帧的区间；右键选择“删除选中区间”。只裁该片段，其他片段内容和其他音频起点保持原样；视频轨道后续片段自动接上。未选中片段、空白处或其他片段内不能建立此选区。
6. 单击片段块选中整个片段，按 Delete 或右键可删除该片段，或在“片段倍速”中设置 0.25～4 倍 / 自定义 0.1～16 倍。片段颜色跟随素材，拖动和拆分时保持一致。
7. Ctrl+Z 撤销删除、重排或片段倍速调整；Ctrl+Shift+Z 重做。也可点击“撤销 / 重做”。原来的手动输入帧号面板已移除。
8. “+ / −”或 Ctrl+滚轮缩放时间线；普通滚轮平移；“适合窗口”显示全部片段。
9. 播放按钮两侧和左右方向键分别后退 / 前进 5 秒，可跨片段跳转，自动限制在项目起止位置；文本输入框保持正常编辑。“项目倍速”应用于整个项目，与各片段自己的倍速相乘。片段倍速同步改变时间线长度、预览及导出，音频同时变速。
10. 音频拖入后自动放在视频下方的独立音轨中。拖到音轨的指定位置或拖动音频条可改变起点；可以选中按 Delete 删除、右键调整倍速、Ctrl+Z 撤销。播放时音频与视频同步，导出时与视频原声混合。多个音频重叠时会混合，音频超过视频结尾时保留最后画面直至音频结束。
11. 填写视频名称、输出目录、清晰度和音频选项，点击“导出完整项目”。导出的内容与当前时间线顺序和删除结果一致。

导出清晰度：高清保留项目原分辨率，标准最高 1080p，省空间最高 720p；始终保持画面比例，小视频不放大。下拉选项及导出摘要显示具体输出宽高，与实际 FFmpeg 参数一致。竖屏会使用对应的竖屏尺寸。

“保留视频原声”只控制视频自带声音；独立音轨始终参与预览及导出。纯音频项目也可试听，导出为带黑色画面的 MP4。

项目画面尺寸采用最初加入的视频，帧率在首次建立时间线时确定（先加入音频时为 30 帧/秒），重排时保持稳定；其他素材按比例完整显示。
有声与无声片段混用时补齐静音。原视频始终保持原样；重名导出自动另存，可取消导出。
录制中关闭窗口会停止并保存；导出中关闭窗口会等待导出完成。

安装后桌面与应用菜单的名称为“神录剪”，悬浮简介为“随手一录，轻松一剪。”。
可执行文件：`~/.local/bin/shenlujian`。
设置保存于：`~/.config/Codeme/shenlujian.conf`，安装更新时已迁移原录屏参数。
项目目录：`~/ffmpeg_screen_recorder/`。
录屏默认输出目录：`~/ffmpeg_screen_recorder/video/`；已有视频也已迁移到此处，保留原子目录。

重新打包：`./build_shenlujian.sh`；安装：`./install_shenlujian.sh`。
运行依赖本机 FFmpeg，视频播放依赖 Qt / GStreamer（构建时已安装对应后端）。

预览按源视频比例和面板宽度自动调整，缩放窗口时仍完整显示。
预览采用软件解码以避开本机硬件视频转换失败；较大视频会在后台生成轻量预览。
首次打开时可以先播放原视频，预览准备完成后自动切换；逐帧定位与导出始终使用原视频。
预览缓存位于 `~/.cache/shenlujian/preview/`，不放入视频目录。
[GStreamer 官方说明](https://gstreamer.freedesktop.org/documentation/gstreamer/running.html) 记录了应用使用的解码优先级设置方式。

## 验证

检查项目片段重排、颜色固定、独立倍速、整段删除、选中片段内区间删除、撤销重做、单源分段的逐帧导出和音频变速。
桌面检查覆盖素材拖入项目、完整项目总时长、跨视频定位与连续播放、实际鼠标拖动、双击选区、右键删除、Ctrl+Z，以及导出逐段画面与时间线一致。
回归录屏保存和录屏导入；检查源文件哈希保持不变。
新增检查覆盖原生 F9/F10 全局按键、最小化录制、1080p / 2K / 4K / 奇数自定义尺寸的实际录制与 ffprobe 核对、刚开始即停止、鼠标框选的像素颜色、Delete 及撤销、跨片段 5 秒跳转、文本编辑不受影响和三档实际导出尺寸。
坐标检查覆盖 100%、125%、200% 和不同显示缩放 / 屏幕原点；另在真实 200% Qt 缩放下录制已知位置窗口并检查原生像素。

素材与音轨检查覆盖默认全屏和双屏选择逻辑、素材库 Delete、音频导入和波形、拖动音轨、同步试听、独立音轨删除与撤销、声音超出视频时长，以及用实际导出声音的频率检验起点和视频原声混合。
